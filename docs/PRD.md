# PRD: Tune Share Hub

## 목표

음악 취향과 플레이리스트를 공유하는 프론트엔드 경험을 빠르게 검증한다.

## 사용자

- 플레이리스트를 만들고 공유하려는 음악 사용자
- 다른 사용자의 음악 취향을 탐색하려는 사용자

## 핵심 기능

1. 플레이리스트 또는 음악 콘텐츠 목록을 탐색한다.
2. 상세 화면에서 콘텐츠 정보를 확인한다.
3. 향후 백엔드 API와 연동할 수 있는 프론트엔드 구조를 유지한다.

## MVP 제외 사항

- 서버 렌더링 전환
- 복잡한 오프라인 캐싱
- 대규모 상태 관리 라이브러리 도입

## 디자인

- 앱 첫 화면은 실제 사용 화면이어야 하며 마케팅 랜딩 페이지처럼 구성하지 않는다.
- 반복 사용에 적합한 간결한 UI를 우선한다.
